# Product voice (evaluators & pitches)

**Audience:** FIAB, BIND, 500 LATAM, YC, technical reviewers.

## Prefer

- Offline installable package (~55K)
- SHA-256 evidence ledgers (internal folio)
- Stability / governance kernel
- Frozen genesis root (fail-closed)
- Conceptual HE bridge (not compiled TFHE in the wheel)
- Reproducible CI + Termux aarch64
- Explicit limits: not CNBV, not an LLM, $0 MRR, 0 paying customers

## Avoid in product surface

- Presenting internal module names as industry standards
- Regulatory or certification language
- Implying production banking software
- Lab-only research titles as product features

## Internal names → neutral reading

| Internal | Neutral |
|----------|---------|
| PPRH | Governance gateway (project-specific) |
| Kernel Sigma | Stability kernel module |
| PLAM / Anexo Q | Research containment notes (lab) |

Lab code and history stay in the repo; they simply are not the pitch.
