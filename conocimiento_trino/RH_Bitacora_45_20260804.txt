I. Los Primeros Principios de la Contención (El Planteamiento)
El Caos Gravitacional (El Problema Clásico): Tres cuerpos interactuando bajo atracción mutua generan un sistema no lineal donde una aproximación cercana provoca una división por cero (la singularidad o colapso infinito del sistema).
El Principio de Aislamiento Estadístico (\epsilon = 1e-5): Introducimos una constante de contorno en la matriz para evitar que las partículas colapsen puntualmente, previniendo la singularidad y manteniendo la estabilidad del flujo sin alterar las leyes físicas fundamentales.
La Bifurcación 1 \rightarrow 4 (Matriz de Oposición de Fase): Cada posición de los cuerpos se descompone en los canales tensoriales ortogonales (S, O, N, I / Pico y Valle), permitiendo que la interacción de las fuerzas se module geométricamente de forma pasiva.

import json
import hashlib
import math
datetime_stamp = "2026-07-22T03:23:31.970Z"

class NodoRomeoHydraTresCuerpos:
    def __init__(self, x1, y1, x2, y2, x3, y3):
        # Posiciones iniciales de los tres cuerpos
        self.cuerpos = [
            {"id": "CUERPO_ALPHA", "x": x1, "y": y1, "vx": 0.1, "vy": -0.2},
            {"id": "CUERPO_BETA",  "x": x2, "y": y2, "vx": -0.1, "vy": 0.2},
            {"id": "CUERPO_GAMMA", "x": x3, "y": y3, "vx": 0.0, "vy": 0.0}
        ]
        self.eps = 1e-5  # Aislamiento estadístico para evitar singularidad (división por cero)

    def calcular_paso_convexo(self, dt=0.01):
        fuerzas = [{"fx": 0.0, "fy": 0.0} for _ in self.cuerpos]
        
        # Interacción mutua de los tres cuerpos (Gravedad con contención convexa)
        for i in range(len(self.cuerpos)):
            for j in range(len(self.cuerpos)):
                if i != j:
                    dx = self.cuerpos[j]["x"] - self.cuerpos[i]["x"]
                    dy = self.cuerpos[j]["y"] - self.cuerpos[i]["y"]
                    dist_sq = dx**2 + dy**2 + self.eps**2  # Contención de singularidad del agujero negro
                    dist = math.sqrt(dist_sq)
                    
                    # Fuerza proporcional a la atracción normalizada
                    f = 1.0 / (dist_sq * dist)
                    fuerzas[i]["fx"] += dx * f
                    fuerzas[i]["fy"] += dy * f

        # Actualización de vectores de posición y velocidad
        delta_log = []
        for i, cuerpo in enumerate(self.cuerpos):
            cuerpo["vx"] += fuerzas[i]["fx"] * dt
            cuerpo["vy"] += fuerzas[i]["fy"] * dt
            cuerpo["x"] += cuerpo["vx"] * dt
            cuerpo["y"] += cuerpo["vy"] * dt
            
            delta_log.append({
                "id": cuerpo["id"],
                "pos_x": round(cuerpo["x"], 4),
                "pos_y": round(cuerpo["y"], 4)
            })
            
        return delta_log
