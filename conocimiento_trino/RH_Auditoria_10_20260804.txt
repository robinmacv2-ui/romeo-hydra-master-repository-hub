1. Resumen ejecutivo
Se establece un marco de gobernanza legal para sistemas de inteligencia artificial que operan en el sector bancario y
financiero. El marco combina una capa normativa trazable a fuentes legales y estándares internacionales con una capa
matemática (CLC v2) que representa dichas restricciones como un conjunto admisible C, un potencial de estabilidad L,
un operador de proyección PLAM y el mecanismo de ε-Invarianza. El objetivo es garantizar que todo sistema de IA
permanezca dentro del espacio de estados legalmente admisibles, con contención determinista (propiedad de 0
escapes), trazabilidad completa y activación automática de controles cuando se aproxima a la frontera de
incumplimiento.
2. Arquitectura jurídica multicapas
Las fuentes normativas se organizan en siete capas. Cada restricción matemática del formalismo CLC debe poder
trazarse a una norma o estándar específico.

3. Formalismo matemático CLC (capa 7)
3.1 Espacio de estados y conjunto admisible
Sea un sistema de IA bancaria modelado como la quíntupla A = (X, Θ, Π, Γ, Σ), donde X son datos de entrada, Θ
parámetros del modelo, Π políticas regulatorias, Γ gobernanza y Σ estado operativo. El espacio de configuración se
denota Ω. El conjunto de estados admisibles es
 C = { x ∈ Ω | Φ(x) = 1 }, Φ(x) = ■i Ci(x)
donde cada Ci : Ω → {0,1} es una restricción normativa. Cuando las restricciones son lineales o convexificables, C es un
politopo convexo.
3.2 Operador de proyección PLAM
PLAM : Ω → C ∪ {⊥} se define por
 PLAM(x) = ΠC(B(x)) si x ∈ C,
 PLAM(x) = ⊥ si x ∉ C.
ΠC es la proyección métrica sobre C; B(x) representa la transformación de bifurcación (despliegue 1→4) cuando el
sistema se aproxima a la inestabilidad; ⊥ denota el estado de colapso (bloqueo preventivo, propiedad de 0 escapes).
3.3 ε-Invarianza
Sea ε > 0 el margen de seguridad respecto a la frontera ∂C y d(x, ∂C) = infy∈∂C ■x − y■. Entonces:
 d(x, ∂C) > ε ⇒ estado seguro (operación normal)
d(x, ∂C) ≤ ε ⇒ activación del modo de contención.
La contención implica suspensión de la decisión automática, escalamiento a supervisión humana, registro en el ledger e,
si procede, bloqueo preventivo.
3.4 Potencial de estabilidad
 L(x) = α Φ(x) − β R(x) + γ Explainability(x) + δ Governance(x) + η Robustness(x)
Un equilibrio regulatorio se caracteriza por ∇L(x) = 0. La convexidad local requiere ∇²L(x) ■ 0. La señal de alerta se
produce cuando λmin(∇²L(x)) → 0■.

5. Flujo operativo y máquina de estados
1. Evaluación de todas las restricciones Ci (Anexos A–L).
2. Verificación de pertenencia a C = ■ {x | Ci(x)=1}.
3. Si x ∈ C y d(x, ∂C) > ε → operación en producción.
4. Si d(x, ∂C) ≤ ε → contención + supervisión humana obligatoria.
5. Si x ∉ C → PLAM(x) = ⊥ (bloqueo) + auditoría inmediata.
6. Registro inmutable de todo evento en el ledger diferencial ∆.

6. Requisitos de implementación
 Separar en código y documentación la capa normativa (predicados booleanos auditables) de la capa CLC (geometría,
proyección y estabilidad).
 Mantener trazabilidad explícita de cada Ci a su artículo o estándar de origen.
 Calcular o aproximar de forma continua d(x, ∂C) y λmin(∇²L).
 Implementar ledger append-only con marca temporal, versión de modelo y responsable.
 Definir y documentar los umbrales ε y τ de forma revisable.
 Realizar pruebas periódicas de contención (red-team de cumplimiento).
 Revisar el mapeo normativo al menos anualmente o ante cambios regulatorios materiales.
7. Limitaciones y alcance
La capa CLC es un modelo matemático de representación, proyección y contención. No sustituye la interpretación
jurídica de las normas ni constituye asesoría legal. La convexidad de C y de L debe demostrarse caso a caso. El
operador PLAM requiere una definición precisa de la proyección ΠC en cada implementación. Este dosier debe ser
validado por las áreas jurídica, de cumplimiento y de riesgos de cada entidad antes de su adopción operativa.
Principio rector. Toda decisión automatizada de un sistema de IA bancaria debe satisfacer Φ(x) = 1. El formalismo CLC
no sustituye la norma: la representa, la proyecta y la protege mediante contención geométrica determinista.
