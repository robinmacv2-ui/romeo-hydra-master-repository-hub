La arquitectura de seguridad que estamos construyendo es el cimiento de la confianza en **ROMEO-HYDRA**. Al materializar core/security/root_authority.py, completamos el par necesario para el control de integridad: el **Firmante** (que inyecta la autoría) y la **Autoridad Raíz** (que valida la soberanía).
Sin esta autoridad, el sistema podría ser víctima de "estados inyectados" sin legitimidad. Con este módulo, cada inferencia o cambio de estado ahora puede ser verificada contra tu identidad raíz.
### 1. Implementación: core/security/root_authority.py
Este módulo se encargará de cargar tu **clave pública** (la cual es pública y segura de tener en el repositorio) y validar las firmas emitidas por tu **clave privada** (que reside solo en tu entorno local).
```python
import json
from cryptography.hazmat.primitives.asymmetric import ed25519
from cryptography.hazmat.primitives import serialization
class RootAuthority:
    def __init__(self, public_key_path: str):
        """
        La autoridad raíz solo necesita acceso a la clave pública 
        para verificar la autenticidad de los estados.
        """
        with open(public_key_path, "rb") as key_file:
            self._public_key = serialization.load_pem_public_key(
                key_file.read()
            )
    def _canonicalize(self, payload: dict) -> bytes:
        """
        Replicamos la lógica del Signer para garantizar que el 
        hash de validación sea idéntico al de creación.
        """
        return json.dumps(payload, sort_keys=True).encode("utf-8")
    def verify(self, payload: dict, signature_hex: str) -> bool:
        """
        Valida que el payload fue firmado por la clave privada 
        correspondiente a la clave pública de la ERCA.
        """
        data = self._canonicalize(payload)
        signature = bytes.fromhex(signature_hex)
        try:
            self._public_key.verify(signature, data)
            return True # Firma válida
        except Exception:
            return False # Firma inválida o alteración detectada
```
### 2. Integración: El "Sello de Integridad"
Ahora que tienes ambos módulos (signer.py y root_authority.py), la lógica en tu main.py (o en tu orquestador) debería verse así para cada transición de estado:
 1. **Generación**: El sistema crea el estado y lo firma con Signer.
 2. **Validación**: Antes de procesar cualquier dato, RootAuthority verifica la firma.
 3. **Auditoría**: Si verify devuelve False, el sistema debe abortar inmediatamente la operación. Esto es lo que garantiza que tu *framework* de gobernanza tenga la **integridad absoluta** que definimos en los documentos de diseño.
