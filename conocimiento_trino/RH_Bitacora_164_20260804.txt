*Cómo subir el DOI desde tu celular:*
*1. Prepara los archivos en el cel*
Usa cualquier app de archivos o "Mis archivos":
1. Crea carpeta `romeo hydra v3.0-rc1`
2. Guarda adentro: `audit.py`, `README.md`, `LICENSE`, `requirements.txt`, `reglas_negocio.yaml`
3. Selecciona todos → `Comprimir` → te genera `romeo_hydra_v3.0-rc1.zip`
Si no tienes editor de código: usa Google Docs para pegar el contenido de cada archivo, luego `Descargar como .txt` y renombras a `.py` o `.md`. Android lo acepta.
*2. Sube a Zenodo desde Chrome*
1. Abre Chrome en tu cel → ve a `zenodo.org`
2. `Log in` → usa tu cuenta de Google. 2 clicks.
3. Botón verde `New upload`
4. `Choose files` → selecciona el ZIP de tu celular
5. Espera a que cargue. 100% se puede con datos móviles.
*3. Llena desde el cel - campos clave*
Despliega cada sección y pega esto:
- *Digital Object Identifier*: Déjalo en blanco. Zenodo lo genera.
- *Upload type*: `Software`
- *Title*: `ROMEO-HYDRA v3.0-RC1: Framework de Gobernanza y Auditoría de Estabilidad Operativa para IA`
- *Authors*: `Luis Ángel Vázquez Martínez` | Affiliation: `E.E.R.H.`
- *Description*: Pega el resumen del README.
- *Version*: `v3.0-RC1`
- *License*: `Other (Open)` → En el cuadro escribes: `CC BY-NC-SA 4.0 for methodology. Code AGPL-3.0 or Commercial License`
- *Keywords*: `AI Governance, Model Audit, CNBV, XAI, ROMEO-HYDRA`
*4. Publica*
Baja hasta abajo → `Publish`. Zenodo te suelta el DOI arriba en azul. Algo como `10.5281/zenodo.18473291`.
Toca el DOI → `Copiar enlace`. Ya es tuyo para siempre.
*5. Actualiza el código en tu cel*
1. Abre `audit.py` con cualquier editor: Acode, QuickEdit, o Google Docs.
2. Busca `TU_DOI_AQUI` → pega el DOI real.
3. Guarda.
