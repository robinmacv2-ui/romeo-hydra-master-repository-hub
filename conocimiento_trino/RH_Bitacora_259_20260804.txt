## 3. Arquitectura del Sistema (Los Cuatro Regímenes)
El framework ROMEO-HYDRA opera encapsulando el proceso de inferencia dentro de cuatro regímenes estrictos, los cuales actúan como "leyes físicas" inmutables para el modelo:
* **Alpha (Logical Invariants):** Verificación de restricciones axiomáticas. Detecta contradicciones lógicas y rechaza estados de entrada inválidos antes de que contaminen el procesamiento.
* **Beta (Jacobian Sensitivity):** Analiza la "fricción" calculando cuánto cambia el estado interno ante perturbaciones de entrada. Aplica amortiguación para penalizar la volatilidad algorítmica.
* **Gamma (Dialectical Pruning):** Reduce el espacio de inferencias descartando ramas de decisión que superen los umbrales de entropía tolerables, conteniendo la "alucinación" matemática.
* **Delta (Traceability):** Registro inmutable (*append-only*) que captura la entrada inicial, evaluaciones de Alpha, métricas de fricción de Beta, y decisiones de Gamma, garantizando la auditoría forense total del sistema.

```python
"""
ROMEO-HYDRA Framework - Core Module: Alpha
Version: 3.0-RC1
Author: Luis Ángel Vázquez Martínez
Objective: Structural coherence validation and deterministic anomaly detection.
"""
from typing import Dict, Any, List, Tuple
class AlphaValidator:
    def __init__(self, rule_manifest: Dict[str, Any] = None):
        """
        Inicializa el validador Alpha con un manifiesto de reglas axiomáticas.
        Si no se provee ninguno, se cargan las reglas estructurales por defecto.
        """
        self.rules = rule_manifest or {
            "required_fields": ["system_state", "inference_vector", "timestamp"],
            "restricted_bounds": {"confidence": (0.0, 1.0), "entropy": (0.0, 10.0)},
            "mutual_exclusions": [("stable", "volatile")]
        }
    def validate_structure(self, payload: Dict[str, Any]) -> Tuple[bool, List[str]]:
        """
        Fase 1: Verifica que la entrada tenga el formato y campos esperados.
        Retorna un booleano y una lista de errores estructurales si existen.
        """
        errors = []
        if not isinstance(payload, dict):
            return False, ["El payload de entrada debe ser un diccionario jerárquico."]
        for field in self.rules["required_fields"]:
            if field not in payload:
                errors.append(f"Falta el campo estructural crítico: '{field}'.")
        return len(errors) == 0, errors
    def detect_contradictions(self, payload: Dict[str, Any]) -> List[str]:
        """
        Fase 2: Identifica contradicciones lógicas y violaciones de límites operativos.
        """
        contradictions = []
        # Verificar límites de variables restringidas
        bounds = self.rules.get("restricted_bounds", {})
        for variable, (min_val, max_val) in bounds.items():
            if variable in payload:
                val = payload[variable]
                if not (min_val <= val <= max_val):
                    contradictions.append(
                        f"Violación de límites operacionales: '{variable}' ({val}) fuera de rango [{min_val}, {max_val}]."
                    )
        # Verificar exclusiones mutuas (estados lógicos incompatibles simultáneos)
        system_state = payload.get("system_state", [])
        if isinstance(system_state, list):
            for state_a, state_b in self.rules.get("mutual_exclusions", []):
                if state_a in system_state and state_b in system_state:
                    contradictions.append(
                        f"Contradicción lógica detectada: Estados mutuamente excluyentes activos simultáneamente ('{state_a}' AND '{state_b}')."
                    )
        return contradictions
    def evaluate_coherence(self, has_valid_structure: bool, contradictions: List[str]) -> float:
        """
        Fase 3: Calcula un score de coherencia determinista (de 0.0 a 1.0).
        Si la estructura falla, la coherencia es nula.
        """
        if not has_valid_structure:
            return 0.0
        # Cada contradicción reduce linealmente la puntuación de coherencia.
        # En producción, esto se vincula a la matriz de peso del Régimen Beta.
        penalty_per_contradiction = 0.25
        score = 1.0 - (len(contradictions) * penalty_per_contradiction)
        return max(0.0, score)
    def generate_report(self, payload: Dict[str, Any]) -> Dict[str, Any]:
        """
        Fase 4: Ejecuta la suite secuencial y produce el reporte estructurado de auditoría.
        """
        is_valid, structural_errors = self.validate_structure(payload)
        contradictions = self.detect_contradictions(payload) if is_valid else []
        coherence_score = self.evaluate_coherence(is_valid, contradictions)
        status = "COMPLIANT" if (is_valid and not contradictions) else "ANOMALOUS"
        if not is_valid:
            status = "STRUCTURAL_FAILURE"
        return {
            "module": "Alpha",
            "status": status,
            "coherence_score": coherence_score,
            "structural_validation": {
                "passed": is_valid,
                "errors": structural_errors
            },
            "logical_audit": {
                "contradictions_detected": len(contradictions) > 0,
                "anomalies": contradictions
            }
        }
```
