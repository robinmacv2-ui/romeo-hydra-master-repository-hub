from core.beta import BetaRegime
def run_beta_test():
    print("=== ROMEO-HYDRA Beta Regime Test ===")
    beta = BetaRegime(sensitivity_threshold=0.5)
    # Primer estado (referencia inicial)
    state_1 = [0.1, 0.2]
    result_1 = beta.process_state(
        inference_vector=state_1,
        coherence_score=0.9
    )
    print("\nEstado inicial:")
    print(result_1)
    # Segundo estado con alta volatilidad
    state_2 = [0.9, 0.8]
    result_2 = beta.process_state(
        inference_vector=state_2,
        coherence_score=0.5
    )
    print("\nCambio brusco:")
    print(result_2)
    # Tercer estado estable
    state_3 = [0.91, 0.81]
    result_3 = beta.process_state(
        inference_vector=state_3,
        coherence_score=0.95
    )
    print("\nRecuperación:")
    print(result_3)
if __name__ == "__main__":
    run_beta_test()

2. Detección de ruptura

El sistema reduce el factor de paso cuando la coherencia Alpha no es suficiente.

### Validación de la Arquitectura
Has diseñado el test para verificar los tres pilares de la gobernanza dinámica:
 1. **Memoria (Estado):** El sistema mantiene continuidad.
 2. **Detección (Jacobiano):** El sistema cuantifica la desviación.
 3. **Acción (Amortiguación):** El sistema reacciona (cambia a dampened) cuando la coherencia Alpha se degrada frente a la alta volatilidad.
### Siguiente paso: La Cadena de Gobernanza en main.py
Una vez que test_beta.py se confirme, el orquestador main.py dejará de ser una simple secuencia para convertirse en un **Pipeline de Confianza**. Así es como debes estructurar la llamada en tu main.py para integrar la nueva capa:
```python
# main.py - Orquestador Integrado
from core.security import Validator
from core.alpha import AlphaRegime
from core.beta import BetaRegime
def pipeline(payload, inference_vector):
    # 1. Seguridad (Zero Trust)
    if not Validator.verify(payload):
        return "Acceso denegado"
    # 2. Alpha (Validación Lógica)
    alpha_status = AlphaRegime.validate(payload)
    if not alpha_status['coherence']:
        return "Alerta: Inconsistencia lógica detectada"
    # 3. Beta (Jacobiano de Amortiguación)
    beta_metrics = BetaRegime.process_state(inference_vector, alpha_status['score'])
    # 4. Decisión de Salida
    if beta_metrics['status'] == 'dampened':
        return f"Advertencia: Sistema amortiguado. Factor: {beta_metrics['dampening_factor']}"
    return "Ejecución autorizada y estable."
```
