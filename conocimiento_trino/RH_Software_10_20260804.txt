### III. El Corazón del Jacobiano: `/core/beta.py`
Aquí reside la lógica matemática del Regimen Beta. Este módulo calcula la sensibilidad del sistema y penaliza la inestabilidad.
```python
import numpy as np
class JacobianoCoherencia:
    """
    Regimen Beta: Adaptive Coherence.
    Calcula la sensibilidad del sistema mediante la matriz Jacobiana.
    """
    def __init__(self, threshold=0.85):
        self.threshold = threshold
        self.penalty_factor = 2.5
    def calcular_volatilidad(self, jacobiano_matriz):
        """
        Calcula la norma de Frobenius de la matriz Jacobiana.
        ||J||_F = sqrt(sum(abs(J_ij)^2))
        """
        norma = np.linalg.norm(jacobiano_matriz, ord='fro')
        return norma
    def evaluar_estabilidad(self, matriz_j):
        """
        Si la volatilidad excede el threshold, penaliza la salida.
        """
        volatilidad = self.calcular_volatilidad(matriz_j)
        if volatilidad > self.threshold:
            print(f"[REGIMEN BETA ALERT] Volatilidad detectada: {volatilidad:.4f}")
            return True, volatilidad * self.penalty_factor
        return False, 1.0  # Factor de escala neutral
```
### IV. Nota Técnica sobre el Regimen Beta
La lógica implementada arriba sigue el principio de **Coherencia Adaptativa**:
 1. **Representación Matemática:** Si el sistema de IA es representado por una función vectorial F(x), la matriz Jacobiana J es la derivada de F respecto a x.
 2. **Detección:** \vert{}\vert{}J\vert{}\vert{}_F (Norma de Frobenius) mide cuánto cambia la salida del sistema ante variaciones mínimas en la entrada.
 3. **Respuesta:** Cuando el framework detecta que el sistema es demasiado "sensible" (la IA está empezando a alucinar o volverse errática), el *Jacobiano* dispara un factor de penalización que suaviza la respuesta del modelo, devolviéndolo a un estado de coherencia.

#### 1. Regimen Delta: Audit Ledger (reg_delta.ps1)
Es el corazón de la trazabilidad. Utiliza Get-FileHash para garantizar que cada entrada sea inmutable.
```powershell
# reg_delta.ps1
function Write-AuditEntry {
    param([string]$message)
    $timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
    $entry = "[$timestamp] $message"
    $hash = ($entry | Out-String | Get-FileHash -Algorithm SHA256).Hash
    "$entry | Hash: $hash" | Out-File -FilePath "audit.log" -Append
}
```
#### 2. Regimen Beta: Jacobiano (reg_beta.ps1)
Calcula la volatilidad de los datos.
```powershell
# reg_beta.ps1
function Get-JacobianMetric {
    param([array]$data)
    # Cálculo simple de varianza como proxy de volatilidad
    $mean = ($data | Measure-Object -Average).Average
    $variance = ($data | Measure-Object -StandardDeviation).StandardDeviation
    return $variance # Penaliza la dispersión
}
```
